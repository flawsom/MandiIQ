This page probes both directly and reports what each one says about itself, then explains the gap between the newest price it holds and today. Downtime timeline

One entry per transition between answering /health and not answering it, written by the 60-second check the shared page shell (site.js) runs on every page. This is the long form of the record the other pages show in short: this is a page, not a monitor, an outage that begins and ends while no tab is open is invisible, an entry can never be more precise than the 60-second check, and the reason shown is the text the instance or the platform edge returned - never a guess about it. Entries are kept in this browser only, capped to the last few outages per instance, and clearing site data erases them. The pill in the header is the one-line form of this list.
