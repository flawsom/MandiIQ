ℹ️ About This Monitor

This page fetches live data from the MandiIQ API and GitHub Actions API every 30 seconds.

  • Dashboard Cache — Status of the in-memory Grafana dashboard JSON cache (fresh / stale / error).
  • md5 Hash — Hash of the loaded dashboard JSON. Changes when the file on disk is updated.
  • Last Refresh — When the cache was last cleared and reloaded via webhook or admin endpoint.
  • File Age — How long since the dashboard JSON file was last modified on disk.

Data sources: GET /admin/dashboard-status and GET /repos/flawsom/MandiIQ/actions/workflows/dashboard-heartbeat.yml/runs.

⋆ A green dot means the last heartbeat checked in within 70 minutes.
⋆ The hash timeline shows stability: repeated identical hashes = no changes; a new hash = dashboard was updated.

⚠️ CORS note: If you see a persistent error banner, the Render API may not be sending Access-Control-Allow-Origin headers. The API must allow requests from your domain for this page to work.
